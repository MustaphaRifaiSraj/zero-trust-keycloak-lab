# Zero Trust Mini-Company Simulation

A hands-on Identity and Access Management (IAM) lab built with Keycloak, Docker and Ubuntu on VMware.

**Status: in progress.** I am building this step by step and recording each stage in this repository's history.

## Progress
- [ ] Virtual machine and Docker
- [ ] Keycloak running
- [ ] Company realm, departments and roles (RBAC)
- [ ] Bulk employee import from CSV via the Admin REST API
- [ ] Single Sign-On across three department apps
- [ ] Multi-Factor Authentication for Finance
- [ ] LDAP federation
